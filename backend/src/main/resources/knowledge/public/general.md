# Bembos Events - informacion general

Bembos Events permite consultar sedes, salones, paquetes, tematicas y servicios adicionales disponibles en el catalogo publico.

El cliente puede consultar la disponibilidad de un salon para una fecha y un horario antes de crear una reserva.

Los precios, capacidades, disponibilidad y estados deben provenir de los servicios del backend. El asistente no debe inventar esos datos.

Una respuesta de conocimiento es informativa. Las operaciones que crean o modifican datos se validan mediante los servicios de negocio correspondientes.
