# Bembos Events - chat y atencion

El chat de Bembos Events mantiene conversaciones y mensajes asociados al cliente autenticado.

Mientras la conversacion esta siendo atendida por el bot, el asistente puede usar capacidades permitidas de solo lectura o preparar informacion para una gestion posterior.

Cuando una conversacion requiere atencion humana puede escalarse al encargado correspondiente. Una conversacion escalada deja de ser gestionada automaticamente por la IA.

La IA no tiene privilegios especiales para aprobar pagos, cambiar estados o saltarse las validaciones del backend.
